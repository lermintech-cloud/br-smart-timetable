# BR Smart Timetable · โรงเรียนบ้านไร่
ระบบจัดตารางสอนออนไลน์ (Cloudflare Pages + Functions + D1) · พัฒนาโดย ครูเฉลิมพล จันทร์แดง

## ติดตั้ง
1. `npm i -g wrangler && wrangler login`
2. `wrangler d1 create br-timetable` → ใส่ `database_id` ใน `wrangler.toml`
3. `wrangler d1 execute br-timetable --remote --file=db/schema.sql` (รันซ้ำได้ปลอดภัย)
4. push ขึ้น GitHub → Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git (Build command ว่าง, Output `public`)
5. Settings → Bindings → D1 database ชื่อ `DB` เลือก `br-timetable` แล้ว Deploy ใหม่

ทดสอบในเครื่อง: `wrangler d1 execute br-timetable --local --file=db/schema.sql && wrangler pages dev public`

## ความปลอดภัย (ไม่มีล็อกอิน)
ใครมีลิงก์ก็แก้ข้อมูลได้ แนะนำเปิด **Cloudflare Access** (Zero Trust, ฟรีไม่เกิน 50 ผู้ใช้) ครอบโดเมนของระบบ
และดาวน์โหลดไฟล์สำรองจากเมนู "ฉบับตาราง/สำรอง" เป็นประจำ

## เกณฑ์ตรวจรับ (ทดสอบก่อนเปิดใช้จริง)
- [ ] เพิ่มครู วิชา ชั้น ห้อง เวลาเรียน แล้วจัดตารางได้ทั้งคอมและมือถือ
- [ ] ลากวาง/ย้ายคาบ ระบบไม่ยอมให้ครู ห้อง ชั้นชนคาบ และไม่ให้วางช่วงพัก
- [ ] สอนแทนแล้วตารางประจำไม่เปลี่ยน ครูแทนที่ติดคาบเลือกไม่ได้
- [ ] พิมพ์รายครู/รายชั้น/รายห้อง/ทุกคน/รายงาน ด้วย Chrome หรือ Edge และเครื่องพิมพ์จริง
- [ ] เปิดจากอีกเครื่องแล้วเห็นข้อมูลเดียวกัน
- [ ] ดาวน์โหลดไฟล์สำรองและทดลองกู้คืนบนข้อมูลสำเนา

## ข้อมูลตัวอย่าง
รัน `db/sample-1-master.sql` แล้วตามด้วย `db/sample-2-timetable.sql` (หรือไฟล์เดียว `db/sample-data.sql`) ใน D1 Console (หลัง `schema.sql`) เพื่อใส่ครู 8 ท่าน ชั้นอนุบาล 2–ป.6 วิชา ห้อง และตารางสอนตัวอย่าง **คำเตือน: ไฟล์นี้ลบข้อมูลเดิมแล้วแทนที่ทั้งหมด**

## v2.0 มีอะไรใหม่
- ดีไซน์ใหม่ทั้งระบบ: โทนกระดาษอุ่น + กรมท่า, ฟอนต์ IBM Plex Sans Thai, ไอคอนเส้น SVG
- เมนูข้างจัดเป็นกลุ่ม (ภาพรวม / จัดตาราง / เอกสาร / ระบบ) มีคำอธิบายใต้ชื่อเมนู, ป้ายแจ้งจำนวนข้อขัดแย้งและแจ้งเตือนใหม่, เมนูย่อยของข้อมูลพื้นฐาน; มือถือเป็นแถบเมนูด้านล่าง
- **เงาคาบชั้นอื่นขณะลาก**: ลากวิชาหรือคาบเดิมแล้วช่องว่างจะแสดงเงาจางของวิชาที่ชั้นอื่นใช้คาบนั้นอยู่ ช่องสีแดง = ครู/ห้องชน วางไม่ได้, สีเหลือง = ครูที่สอนวิชานี้ติดทุกคน, สีเขียว = วางได้
- ชิปวิชาแสดงจำนวนที่จัดแล้ว/ที่ต้องจัด (เช่น 3/4)
- หน้าต่างเพิ่มคาบ: ครู/ห้องที่ติดคาบเดียวกันเลือกไม่ได้ พร้อมบอกว่าติดชั้นไหน และเลือกครูที่เหมาะสมให้อัตโนมัติ
- แถวหัวตารางและคอลัมน์วันตรึงเวลาเลื่อน, ไฮไลต์วันปัจจุบัน

## v2.2 จัดตารางอัตโนมัติ
- **ต้องรัน `db/schema.sql` ซ้ำหนึ่งครั้ง** (เพิ่มตาราง assignments, ไม่กระทบข้อมูลเดิม): `wrangler d1 execute br-timetable --remote --file=db/schema.sql`
- ข้อมูลพื้นฐาน → การมอบหมายสอน: กำหนดชั้น/วิชา/ครู/ห้อง/คาบต่อสัปดาห์ (กด "นำเข้าจากตารางปัจจุบัน" เพื่อสร้างอัตโนมัติ)
- หน้าจัดตารางสอน → จัดอัตโนมัติ: เลือกเงื่อนไข ดูตัวอย่าง แล้วยืนยัน (ระบบเก็บฉบับก่อนหน้าไว้ให้กู้คืน)

## v2.5 ครู 2 คนต่อคาบ
- คาบสอน 1 คาบใส่ครูได้ 2 คน (เช่น ชั้นที่มีครูประจำชั้น 2 คน) ที่หน้าต่างเพิ่ม/แก้ไขคาบมีช่อง "ครูคนที่ 2" ระบบตรวจคาบชนของครูทั้งสองคน ตารางรายครูของทั้งสองคนจะแสดงคาบนั้น และนับเป็นภาระงานของทั้งคู่
- การมอบหมายสอนมีช่อง "ครูคนที่ 2" ด้วย จัดตารางอัตโนมัติจะกันเวลาของทั้งสองคน
- **ฐานข้อมูลที่ติดตั้งแล้วต้องรัน `db/migrate-v2.5.sql` หนึ่งครั้ง** ก่อน deploy โค้ดใหม่: `wrangler d1 execute br-timetable --remote --file=db/migrate-v2.5.sql` (ติดตั้งใหม่ใช้ schema.sql ได้เลย)
